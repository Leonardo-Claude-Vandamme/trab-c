# Front da Minha Biblioteca

Front-end básico em HTML, Bootstrap e JavaScript para consumir a API.

Para usar:

1. Na raiz do projeto, execute `dotnet run --launch-profile http`.
2. Abra `http://localhost:5194` no navegador.

O ASP.NET Core serve a página e a API na mesma porta. O front lista, cadastra, edita e exclui livros e revistas.
